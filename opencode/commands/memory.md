---
description: "Mostra e gerencia as memórias duráveis do projeto"
---

Use a tool `memory_list` para listar as memórias duráveis deste projeto e apresente-as em uma lista. Pergunte ao usuário se alguma deve ser removida (use `memory_delete` com o ID) ou se algo novo deve ser salvo (use `memory_write`). Não faça nada além disso.
